# DU

Личная передача файлов: [files.example.com](https://files.example.com).

## Использование

- Загрузка через выбор файлов, перетаскивание или вставку из буфера. Папки при перетаскивании собираются в ZIP с сохранением структуры. Перед отправкой виден состав и исключения; исключённое можно вернуть. Учитываются вложенные `.gitignore`, окружения и кэши Python, `target` Rust, `node_modules`, служебные каталоги, `.env` и ключи. `dist`, `build` и `outputs` исключаются только по `.gitignore`. Лимит 100 файлов и 2 ГБ применяется и к содержимому папок.
- Получатель скачивает один файл в оригинале, несколько — ZIP.
- Текст: вставить на главном экране или открыть `</>` в меню, проверить в редакторе и отправить. Подсветка определяется автоматически; `?` означает неопределённый или сомнительный язык. Новый текст получает расширение уверенно определённого языка (`.md`, `.py`, `.js` и другие), иначе `.txt`.
- Одиночный UTF-8 текст или код до 5 МиБ открывается для чтения и копирования. Raw отдаёт исходный текст с теми же паролем и сроком; остальные файлы скачиваются как обычно.
- Просмотр открывается во весь экран; после закрытия его можно открыть иконкой-глазом. Текстовые файлы внутри передачи открываются нажатием на имя в подробностях.
- Markdown открывается оформленным документом; иконка рядом с Raw переключает превью и исходник. На телефоне история и редактор тоже занимают весь экран.
- Карандаш у одиночного текста открывает редактирование: сохранение обновляет ту же ссылку, сохраняя имя, пароль и срок. `</>` в меню создаёт отдельную передачу.
- Плюс добавляет файлы к той же ссылке. В истории можно удалить отдельные файлы или всю передачу.
- Выбор всех файлов внутри передачи очищает её, сохраняя ссылку. Выбор записей в истории и корзина в шапке удаляют передачи и убирают записи. Первое нажатие на корзину показывает `?`, второе подтверждает удаление.
- Срок хранения: 1 час, 6 часов, сутки, 3 дня, 7 дней или ∞. Выбор запоминается в браузере.
- В шестерёнке — предустановки новой загрузки. У готовой передачи и в истории кнопка параметров меняет её срок и пароль. Новый срок считается от момента изменения. Клик по замку создаёт и копирует 6 цифр, двойной убирает пароль; галочка подтверждает копирование. Новые пароли хранятся зашифрованными и доступны владельцу после перезагрузки. Старые пароли, сохранённые только хешем, можно заменить. Изменение пароля отзывает предыдущие разрешения получателей.

До **100 файлов / 2 ГБ** в одной передаче. Общая квота — **20 ГБ**, включая временные файлы при сборке ZIP. Незавершённая загрузка отменяется через сутки. Пауза и продолжение работают, пока открыта страница.

## Настройка

Скопировать `.env.example` в `.env` и заполнить свои значения: домен, пароль владельца из 6 цифр, параметры S3 и Traefik. Все значения в примере условные. `.env` не попадает в Git.

## Деплой

Пуш в `main` запускает проверки и публикацию на server. Приложение работает отдельным Compose-проектом `holder`; другие проекты не затрагиваются.

Файлы хранятся в S3, история — в SQLite в томе `flash-data`. Работает один экземпляр приложения.

## Разработка

Node.js 24.

```sh
npm ci
npm test
npm run build
```

Для запуска: `node --env-file=.env server/main.js`. Для локального адреса добавить `PUBLIC_URL=http://localhost:3000` в `.env`; CORS бакета должен разрешать этот адрес.
